7.3 Gibbs Sampler

The attraction of an algorithm like single component Metropolis-Hastings is that it converts a pp-dimensional problem into pp separate 1-dimensional problems, each if which is likely simple to solve. This advantage is not unlike that seen with coordinate descent algorithms discussed previously. SCMH can however be very exploratory and may not be efficient in exploring the parameter space.

Gibbs sampling is a variant of SCMH that uses full conditional distributions for the proposal distribution for each component. Given a target density π(x)=π(x1,…,xp)π(x)=π(x1,…,xp), we cycle through sampling from π(xi∣x−i)π(xi∣x−i) to update the iith component. Rather than go though an accept/reject step as with Metropolis-Hastings, we always accept, for reasons that will be detailed below.

For example, with a three-component density π(x,y,z)π(x,y,z), the full conditional distributions associated with this density are

π(x∣y,z),π(x∣y,z), π(y∣x,z),π(y∣x,z), and π(z∣x,y).π(z∣x,y).

If our current state is (xn,yn,zn)(xn,yn,zn) at the nnth iteration, then we update our parameter values with the following steps.

  1. Sample xn+1∼π(x∣yn,zn)xn+1∼π(x∣yn,zn)
  2. Sample yn+1∼π(y∣xn+1,zn)yn+1∼π(y∣xn+1,zn)
  3. Sample zn+1∼π(z∣xn+1,yn+1)zn+1∼π(z∣xn+1,yn+1)

At each step of the sampling we use the most recent values of all the other components in the full conditional distribution. In a landmark paper, Geman and Geman showed that if p(xn,yn,zn)p(xn,yn,zn) is the density of our parameters at the nnth iteration, then as n→∞n→∞,

p(xn,yn,zn)→π(x,y,z)p(xn)→π(x)p(yn)→π(y)p(zn)→π(z)p(xn,yn,zn)→π(x,y,z)p(xn)→π(x)p(yn)→π(y)p(zn)→π(z)

7.3.1 Example: Bivariate Normal Distribution

Suppose we want to simulate from a bivariate Normal distribution with mean μ=(μ1,μ2)μ=(μ1,μ2) and covariance matrix

Σ=(σ21ρρσ22)Σ=(σ12ρρσ22)

Although there are exact ways to do this, we can make use of Gibbs sampling too simulate a Markov chain that will converge to a bivariate Normal. At the nnth iteration with state vector (xn,yn)(xn,yn), we can update our state with the following steps.

  1. Sample xn+1∼N(μ1+ρσ1σ2(yn−μ2),σ21(1−ρ))xn+1∼N(μ1+ρσ1σ2(yn−μ2),σ12(1−ρ))

  2. Sample yn+1∼N(μ2+ρσ2σ1(xn+1−μ1),σ22(1−ρ))yn+1∼N(μ2+ρσ2σ1(xn+1−μ1),σ22(1−ρ))

If ρρ is close to 11, then this algorithm will likely take a while to converge. But it is simple to simulate and demonstrates the mechanics of Gibbs sampling.

7.3.2 Example: Normal Likelihood

Suppose we observe y1,…,yniid∼N(μ,τ−1)y1,…,yn∼iidN(μ,τ−1), where τ−1τ−1 is the precision of the Normal distribution. We can use independent priors for the two parameters as

μ∼N(0,w−1)τ∼Gamma(α,β)μ∼N(0,w−1)τ∼Gamma(α,β)

Because the priors are independent here, we will have to use Gibbs sampling to sample from the posterior distribution of μμ and ττ.

Recall that with Bayes’ Theorem, the joint posterior of μμ and ττ is

π(μ,τ∣y)∝π(μ,τ,y)=f(y∣μ,τ)p(μ)p(τ)π(μ,τ∣y)∝π(μ,τ,y)=f(y∣μ,τ)p(μ)p(τ)

where f(y∣μ,τ)f(y∣μ,τ) is the joint Normal density of the observed data.

In the Gibbs sampling procedure there will be two full conditional distributions that we will want to sample from. They are

p(μ∣τ,y)∝f(y∣μ,τ)p(μ)p(τ)∝f(y∣μ,τ)p(μ)∝exp(−τ2∑(yi−μ)2)exp(−w2μ2)=exp(−(nτ+w)2μ2−(∑yi)τμ)=N(τnτ+w∑yi,1nτ+w)p(μ∣τ,y)∝f(y∣μ,τ)p(μ)p(τ)∝f(y∣μ,τ)p(μ)∝exp⁡(−τ2∑(yi−μ)2)exp⁡(−w2μ2)=exp⁡(−(nτ+w)2μ2−(∑yi)τμ)=N(τnτ+w∑yi,1nτ+w)

and

p(τ∣μ,y)∝f(y∣μ,τ)p(μ)p(τ)∝f(y∣μ,τ)p(τ)∝τn2exp(−τ2∑(yi−μ)2)τα−1exp(−τβ)=τα−1+n2exp(−τ[β+12∑(yi−μ)2])=Gamma(α+n2,β+12∑(yi−μ)2)p(τ∣μ,y)∝f(y∣μ,τ)p(μ)p(τ)∝f(y∣μ,τ)p(τ)∝τn2exp⁡(−τ2∑(yi−μ)2)τα−1exp⁡(−τβ)=τα−1+n2exp⁡(−τ[β+12∑(yi−μ)2])=Gamma(α+n2,β+12∑(yi−μ)2)

The Gibbs sampler therefore alternates between sampling from a Normal distribution and a Gamma distribution. In this case, the priors were chosen so that the full conditional distributions could be sampled in closed form.

7.3.3 Gibbs Sampling and Metropolis Hastings

Gibbs sampling has a fairly straightforward connection to the single component Metropolis-Hastings algorithm described earlier. We can reframe the Gibbs sampling algorithm for component ii at iteration nn as

  1. Sample yi∼qi(y∣x(n)i,x(n)−i)=π(y∣x(n)−i)yi∼qi(y∣xi(n),x−i(n))=π(y∣x−i(n)). Here, the proposal distribution simply the full conditional distribution of xixi given x−ix−i.

  2. The acceptance probability is then α(yi∣xi,x−i)=min(π(yi∣x−i)π(xi∣x−i)π(xi∣x−i)π(yi∣x−i),1)=1α(yi∣xi,x−i)=min(π(yi∣x−i)π(xi∣x−i)π(xi∣x−i)π(yi∣x−i),1)=1 The Gibbs sampling algorithm is like the SCMH algorithm but it always accepts the proposal.

7.3.4 Hybrid Gibbs Sampler

Given the relationship between Gibbs sampling and SCMH, we can use this to extend the basic Gibbs algorithm. In some cases, we will not be able to sample directly from the full conditional distribution of a component. In those cases, we can substitute a standard Metropolis-Hastings step with a proposal/acceptance procedure.

For components that require a Metropolis-Hastings step, we will need to come up with a proposal density for those components. In this case, the target density is simply the full conditional of component ii given the other components. For component ii then, the algorithm procedes as

  1. Sample yi∼q(y∣x)yi∼q(y∣x)

  2. Compute the acceptance probability α(yi∣x)=min(π(yi∣x−i)q(xi∣x)π(xi∣x−i)q(yi∣x),1)α(yi∣x)=min(π(yi∣x−i)q(xi∣x)π(xi∣x−i)q(yi∣x),1) We then accept the proposal with probability α(yi∣x)α(yi∣x).

Regardless of whether the proposal is accepted or not, we can move on to the next component of the parameter vector.

7.3.5 Reparametrization

In some Metropolis-Hastings or hybrid Gibbs sampling problems we may have parameters where it is easier to sample from a full conditional of a transformed version of the parameter. For example, we may need to sample from the full conditional p(λ∣⋅)p(λ∣⋅) of a parameter that only takes values between 00 and 11. Doing something like a random walk proposal can be tricky given the restricted range.

One solution is the transform the parameter to a space that has a infinte range. For a parameter λ∈(0,1)λ∈(0,1) we can use the logit transformation to map it to (−∞,∞)(−∞,∞), i.e. 

z=logit(λ)=logλ1−λ.z=logit(λ)=log⁡λ1−λ.

Then we can do the proposal and acceptance steps on the transformed parameter zz, which has an infinite domain. However, we need to be careful that the acceptance ratio is calculated properly to account for the nonlinear transformation of λλ. In this case we need to compute the determinant of the Jacobian of the transformation mapping zz back to λλ.

The algorithm at iteration nn in the transformed space would work as follows.

  1. Sample z⋆∼g(z∣zn)z⋆∼g(z∣zn), where zn=logit(λn)zn=logit(λn) and gg is the proposal density.

  2. Compute α(z⋆∣zn)=min(p(logit−1(z⋆)∣⋅)p(logit−1(zn)∣⋅)g(zn∣z⋆)g(z⋆∣zn)|J(z⋆)||J(zn)|,1)α(z⋆∣zn)=min(p(logit−1(z⋆)∣⋅)p(logit−1(zn)∣⋅)g(zn∣z⋆)g(z⋆∣zn)|J(z⋆)||J(zn)|,1) where |J(z)||J(z)| is the determinant of the Jacobian of the transformation that maps from z↦λz↦λ, i.e. the function logit−1(z)=exp(z)1+exp(z).logit−1(z)=exp⁡(z)1+exp⁡(z).

In R, we can easily compute this Jacobian (and that for any other transformation) with the deriv() function.

Jacobian <- local({
        J <- deriv(~ exp(x) / (1 + exp(x)), "x", 
                   function.arg = TRUE)
        function(x) {
                val <- J(x)
                drop(attr(val, "gradient"))
        }
})
Jacobian(0)
##    x 
## 0.25

Becuase the transformation here is for a single parameter, the determinant is straightforward. However, for a multi-dimensional mapping, we would need an extra step to compute the determinant. The det() function can be used for this purpose, but bear in mind that it almost always makes sense to use the logarithm = TRUE argument to det().

7.3.6 Example: Bernoulli Random Effects Model

Suppose we observe longitudinal binary data that follow

yij∼Bernoulli(λij)logit(λij)=αiαi∼N(μ,σ2)μ∼N(0,D)σ∼InverseGamma(a,b)yij∼Bernoulli(λij)logit(λij)=αiαi∼N(μ,σ2)μ∼N(0,D)σ∼InverseGamma(a,b)

where i=1,…,ni=1,…,n and j=1,…,Gj=1,…,G.

For this example, assume that the hyperparameters aa, bb, and DD are known. The goal is to sample from the posterior of μμ and σσ. The joint posterior of the parameters given the data is

π(μ,σ,α∣y)∝n∏i=1[G∏j=1p(yij∣logit−1(αi)]×φ(αi∣μ,σ2)φ(μ∣0,D)g(σ)π(μ,σ,α∣y)∝∏i=1n[∏j=1Gp(yij∣logit−1(αi)]×φ(αi∣μ,σ2)φ(μ∣0,D)g(σ)

where p()p() is the Bernoulli density, φφ is the Normal density, and g()g() is the inverse gamma density.

To implement the Gibbs sampler, we need to cycle through three classes of full conditional distributions. First is the full conditional for σσ, which can be written in closed form given the prior. In order to compute the full conditional, we simply select everything from the full posterior that has a σσ in it.

p(σ∣⋅)∝[n∏i=1φ(αi∣μ,σ2)]g(σ)=InverseGamma(a+n2,b+12∑(αi−μ)2)p(σ∣⋅)∝[∏i=1nφ(αi∣μ,σ2)]g(σ)=InverseGamma(a+n2,b+12∑(αi−μ)2)

Similarly, we can pick out all the components of the full posterior that have a μμ and the full conditional distribution for μμ is

p(μ∣⋅)∝[n∏i=1φ(αi∣μ,σ2)]φ(μ∣,0,D)=N(DD+σ2/n¯α,σ2/nσ2/n+DD)p(μ∣⋅)∝[∏i=1nφ(αi∣μ,σ2)]φ(μ∣,0,D)=N(DD+σ2/nα¯,σ2/nσ2/n+DD)

where ¯α=1n∑αiα¯=1n∑αi.

Finally, the full conditionals for αiαi can be compute independently because the αiαis are assumed to be independent.

p(αi∣⋅)∝[G∏j=1p(yij∣logit−1(αi))]φ(αi∣μ,σ2).p(αi∣⋅)∝[∏j=1Gp(yij∣logit−1(αi))]φ(αi∣μ,σ2).

Unfortunately, there is no way to simplify this further with the combination of the Bernoulli likelihood and the Normal random effects distribution. Therefore, some proposal/acceptance step will have to be run to sample from the αiαis.
